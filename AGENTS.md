# Orientações do projeto

## Identidade visual da Pratic Limp

Antes de criar ou alterar qualquer interface ou material da marca (site, cartão,
panfleto, apresentação, publicação ou imagem), leia `docs/design-system.md`.
Use esse documento como referência visual obrigatória, inclusive ao gerar prompts
para imagens ou orientar ferramentas externas.

Preserve a identidade do site: ativos oficiais, Manrope e DM Sans, paleta vigente,
espaço livre, curvas suaves e superfícies claras. Siga as adaptações do guia para
impressão. Os cartões e panfletos anteriores são históricos, não modelos visuais
aprovados. Não reutilize seus estilos sem revisão pelo guia.

Se o usuário pedir uma mudança de identidade, atualize também o design system
para manter uma única referência. Instruções explícitas do usuário prevalecem.
Ao entregar peças visuais, confira a lista de revisão do documento e informe
qualquer validação que ainda não foi possível realizar.

## Acervo de artes

A galeria não listada é gerada por `scripts/build-gallery.mjs`. Consulte
`docs/galeria/catalog.mjs` para resolver códigos como `PL-P01-V` (panfleto
institucional atual, verso). Preserve os códigos ao revisar uma peça. Edite o
gerador indicado no catálogo, regenere os arquivos e atualize suas prévias.
Não adicione links para o acervo na home, menus ou sitemap público.
